
# 30-Day Content Calendar Generator

## About
This project generates a 30-day content calendar for brands,
creators, students, and startup founders.

## Features
- Select your target audience
- Choose a social media platform
- Select a content goal
- Generate 30 days of content ideas
- Simple and responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Select your audience, platform, and goal.
4. Click Generate Calendar.

## Future Improvements
- AI-generated content ideas
- Download calendar as PDF or CSV
- User login and saved calendars
